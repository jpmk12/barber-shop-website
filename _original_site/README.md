# Original site archive

This is a byte-for-byte archive of the live `terrys-barbershop.com` site as it
existed on **2026-06-28**, preserved before any modernization work.

Captured by downloading from the apex domain (`terrys-barbershop.com`); the
site is a single static HTML page hosted on GoDaddy (secureserver.net).

## Files

| File | Purpose |
|------|---------|
| `index.html` | The entire site — one XHTML 1.0 page |
| `style.css` | The one stylesheet (float-based, fixed-width layout) |
| `header2.jpg` | Exterior photo of the shop (3072×2920) |
| `back_bar_highedit.jpg` | Interior photo, used as header background (3264×1532) |
| `images/todd.jpg` | Barber Todd Poole |
| `images/add.jpg` | Barber Addison Sanders (commented out in current HTML) |

## Notes / issues with the original

- Not mobile-friendly (fixed widths, floats, no viewport meta tag).
- `windows-1252` charset, XHTML 1.0 Strict doctype, deprecated `<center>` and
  inline `</br>` tags, headings nested inside `<p>`.
- References `images/background.gif` which no longer exists on the server (404/500).
- Facebook Like button via the long-deprecated `all.js` SDK (no longer functions).
- GoDaddy traffic-monitoring script injected at the end.
